.. dropdown:: v0.1.0 -- Redesign In Progress (2026-08)
   :icon: tag
   :class-container: sd-border-success

   ENPM663 rebuilt as "Building AI-Augmented Robotic Systems" (Spring 2027),
   redesigned from the earlier manufacturing-robotics offering.

   - Course structure: 15 weeks (Week 8 Spring Break), 5 team projects (PT1 to
     PT5), 5 quizzes plus an ungraded Week 1 diagnostic.
   - AI direction: LLM agents for task planning (agent loop, tool use via MCP,
     structured output) and VLM grounding with agentic closed-loop replanning;
     classical motion planning (MoveIt2). The VLA frontier is surveyed, not
     built.
   - Stack: Ubuntu 24.04 + ROS 2 Jazzy + Gazebo Harmonic + ARIAC 2025.
   - Grading: 60% team projects / 25% quizzes / 15% peer-review contribution.
   - Lecture stubs authored for all 15 weeks; W9 and W10 framed around the agent
     loop; a VLA survey segment added to W2.
   - Team Project pages (PT1 to PT5) and an ENPM663 setup, reading-material, and
     glossary section replacing the previous C++ course content.

   The site is under active development; content is still being authored.
