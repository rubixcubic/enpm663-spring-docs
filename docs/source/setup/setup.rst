====================================================
Setup
====================================================

This section provides instructions for setting up the development
environment used throughout ENPM663. The full stack is Ubuntu 24.04 + ROS 2
Jazzy + Gazebo Harmonic + ARIAC 2025, plus the AI tooling used in the later
projects.

- **Ubuntu** -- Install Ubuntu Desktop 24.04 LTS (Noble Numbat).
- **ROS 2 and Gazebo** -- ROS 2 Jazzy and Gazebo Harmonic; needed from Week 1.
- **ARIAC and tools** -- ARIAC 2025, MoveIt2, ``py_trees_ros``, and a PDDL
  planner; needed from the first team project onward.
- **AI access** -- an LLM/VLM API account or local open-weight models; needed
  from Week 9 (PT4).
